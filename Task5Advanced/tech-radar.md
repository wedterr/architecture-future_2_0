

# Расширенный технический радар для системы "Будущее 2.0"
[Назад к списку](./README.md)

- 🟩 Adopt — Зеленый квадрат (внедрено/используется).
- 🟨 Trial — Желтый квадрат (пилот/эксперимент).
- 🟧 Assess — Оранжевый квадрат (оценка/изучение).
- ⬜ Hold — Белый квадрат (временно не рекомендуется).
## Архитектурные паттерны и подходы

| Паттерн                     | Статус | Описание                                                      | Обоснование                                                                                          |
|-----------------------------|--------|----------------------------------------------------------------|----------------------------------------------------------------------------------------------------|
| Hybrid Integration          | 🟩 Adopt  | Совместное использование Camel и событийной шины            | Позволяет плавно интегрировать новые сервисы, сохраняя работу legacy систем                       |
| Event-Driven Architecture  | 🟨 Trial  | Асинхронное взаимодействие через события                     | Начало внедрения в отдельных доменах                                                               |
| Domain-Driven Design (DDD) | 🟩 Adopt  | Четкое разделение системы по доменам                         | Помогает структурировать сервисы и события                                                        |
| Saga Pattern               | 🟨 Trial  | Управление распределёнными транзакциями                      | Для обеспечения консистентности в событийной архитектуре                                          |
| Outbox Pattern             | 🟨 Trial  | Гарантированная доставка событий                              | Минимизирует рассинхронизацию данных и событий                                                     |
| Circuit Breaker            | 🟩 Adopt  | Защита от каскадных ошибок                                   | Обеспечивает устойчивость сервисов                                                               |
| Self-service BI            | 🟩 Adopt  | Самообслуживание для аналитики                               | Уменьшает нагрузку на IT и ускоряет принятие решений                                              |

| Технология                 | Статус | Описание                                                    | Обоснование                                                                    |
|----------------------------|--------|--------------------------------------------------------------|--------------------------------------------------------------------------------|
| Apache Camel               | 🟨 Trial  | Легаси интеграционная шина                                 | Поэтапное сокращение, поддержка нынешних процессов                            |
| Apache Kafka               | 🟨 Trial  | Платформа потоковой передачи событий                        | Внедряется для новых и критичных интеграций                                  |

| Kafka Streams              | 🟧 Assess | Потоковая обработка событий                                 | Рассматривается для новых сценариев                                          |
| Confluent Platform         | 🟧 Assess | Расширенный Kafka для enterprise                            | Оценка возможностей расширенного функционала                                |

| Schema Registry            | 🟨 Trial  | Управление схемами сообщений                                | Для обеспечения совместимости и эволюции событий                             |
