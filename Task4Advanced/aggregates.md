# Доменные агрегаты (Domain Aggregates)

## 1. Медицинский домен (Patient Care Context)

### Агрегат Patient (Пациент)
Границы: Включает персональные данные, контактную информацию, медицинскую историю

Инварианты:
- Уникальный идентификатор пациента
- Обязательные поля: ФИО, дата рождения, пол
- Согласие на обработку персональных данных

Ключи:
- PersonalInfo (персональная информация)
- ContactInfo (контактная информация)
- MedicalHistory (медицинская история)
- Consent (согласие на обработку данных)

## 2. Финтех домен (Financial Services Context)

### Агрегат Account (Счёт)

Границы: Включает банковский счёт, баланс, операции

Инварианты:
- Баланс не может быть отрицательным без овердрафта
- Все операции должны быть валидными
- Счёт должен быть связан с клиентом

Ключи:
- Balance (баланс)
- Transaction (транзакция)
- Overdraft (овердрафт)
- Interest (проценты)

### Агрегат Credit (Кредит)
Границы: Включает кредитный продукт, заявку, погашение

Инварианты:
- Кредит не может превышать лимит
- Платежи должны соответствовать графику
- Статус должен быть валидным

Сущности:
- Application (заявка)
- Terms (условия)
- Schedule (график платежей)
- Collateral (залог)


## 3. AI-сервисы домен (Intelligent Diagnostics Context)

### Агрегат Diagnosis (Диагноз)
Границы: Включает AI диагноз, обоснование, рекомендации

Инварианты:
- Диагноз должен быть связан с пациентом
- Обоснование должно быть предоставлено
- Рекомендации должны быть валидными

Ключи:
- Condition (состояние)
- Evidence (обоснование)
- Recommendation (рекомендация)
- Confidence (уверенность)


## 4. Фармацевтический домен (Pharmaceutical Management Context)

### Агрегат Prescription (Рецепт)
Границы: Включает рецепт, назначения, выполнение

Инварианты:
- Рецепт должен быть выписан врачом
- Назначения должны быть валидными
- Выполнение должно соответствовать назначению

Ключи:
- PrescriptionInfo (информация о рецепте)
- Medications (лекарства)
- Dosage (дозировка)
- Instructions (инструкции)

## 5. Оборудование домен (Medical Equipment Context)

### Агрегат Equipment (Оборудование)
Границы: Включает медицинское оборудование характеристики, статус

Инварианты:
- Оборудование должно иметь уникальный серийный номер
- Характеристики должны быть валидными
- Статус должен быть актуальным

Ключи:
- EquipmentInfo (информация об оборудовании)
- Specifications (характеристики)
- Status (статус)
- Location (местоположение)

## 6. Платформа данных (Data Platform Context)

### Агрегат DataProduct (Продукт данных)
Границы: Включает продукт данных, метаданные, SLA

Инварианты:
- Продукт должен иметь владельца
- Метаданные должны быть полными
- SLA должны быть выполнимыми

Ключи:
- ProductInfo (информация о продукте)
- Metadata (метаданные)
- SLA (соглашение об уровне сервиса)
- Quality (качество)

## 7. Портал самообслуживания (Self-Service Analytics Context)

### Агрегат Report (Отчёт)
Границы: Включает отчёт, параметры, выполнение

Инварианты:
- Отчёт должен иметь определение
- Параметры должны быть валидными
- Выполнение должно быть отслеживаемым

Ключи:
- ReportDefinition (определение отчёта)
- Parameters (параметры)
- Execution (выполнение)
- Output (результат)
